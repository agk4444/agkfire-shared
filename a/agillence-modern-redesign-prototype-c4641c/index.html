Patch notes for the Hugo repo

This prototype can't patch your live site — it has no access to the Hugo source. Here's the change list, in priority order. Items 1–3 are the whole "modern" feeling.

01Retire Playfair Display

A 2011 didone argues "craft" while your pitch is "throughput". One line, largest perceived delta available.

--ag-font-heading: 'Playfair Display', Georgia, serif;
--ag-font-heading: 'Inter Tight', system-ui, sans-serif;
02Swap the ALLO / ALMS images

Each card was loading the other's SVG. Trust bug, ships today.

ALLO → alms.svg
ALMS → allo.svg
ALLO → allo.svg
ALMS → alms.svg
03Kill the carousel

Pause-on-hover only = WCAG 2.2.2 failure, hostile on mobile, and it hides your customer logos. Replace with the static hero + trust strip.

<div class="carousel slide" data-bs-ride="carousel">
  <div data-bs-interval="6000" data-bs-pause="hover">
<!-- static hero + static logo bar -->
04Strip inline styles

style="max-height:44px" on the navbar <img> overrides .navbar-brand img — that rule is dead code. Same on dropdown badges.

<img style="max-height:44px" ...>
<img class="brand-logo" ...>
.navbar-brand img { height: 48px; }
05One green, one navy

#a3e635 and rgba(132,204,22,.5) are Tailwind lime-400, not brand olive. --ag-navy-light: #93c5fd is blue-300 wearing a navy name, and .bg-navy-subtle is byte-identical to --ag-slate-200.

rgba(132,204,22,.5)  ·  #a3e635  ·  #93c5fd  ·  #e2e8f0
var(--olive-600)  ·  var(--navy-300)  ·  var(--line)
06Drop the 0.6em mobile body rule

The mobile stylesheet sets body { font-size: 0.6em } under 500px — ~10px text on phones, which is exactly where your buyers read.

@media (max-width:500px){ body{ font-size: 0.6em; } }
/* fluid type instead */
body{ font-size: clamp(1rem, 0.95rem + 0.3vw, 1.125rem); }
07A11y pass

No :focus-visible, no prefers-reduced-motion, duplicate viewport meta, @import for fonts creating a render-blocking waterfall. Both blocks are in this prototype — lift them.

:focus-visible{ outline:3px solid var(--olive-500); outline-offset:3px; }
@media (prefers-reduced-motion:reduce){ *{ transition-duration:.01ms!important; } }
08Self-host, re-crop images

Story cards hotlink wp-content images including nisar-awards-768x1024.jpg — a 3:4 portrait inside a 210px landscape box with object-fit:cover. Standardize 3:2 and drop the cover.

.card-media{ aspect-ratio: 3/2; object-fit: contain; }
Do the redesign and the Hugo upgrade as separate PRs

Your staging site runs Hugo 0.104.2 (~Aug 2023); current is 0.167.0 per Hugo's own Vercel doc (Sept 2026) — roughly 60 minor releases. Hugo 0.146.0 (Nov 2024) rewrote the template system and broke sites on its own. Shipping both together makes a regression unbisectable. Do the design here, then upgrade alone, then re-verify.
