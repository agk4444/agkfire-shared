Why we run

A race built around the moment it matters most

Run for Jeev exists because a 16-year-old in Houston shouldn't have to choose between asking for help and paying for it. Every registration, every donation, every volunteer hour goes to counseling and crisis support for teens — regardless of insurance, regardless of family income.

Last year the field raised enough to fund 1,400 counseling sessions. This year we're aiming higher, and the only thing standing between here and there is people showing up.

For whoever edits Elementor

Mobile + contrast patches

1 · Global colors — the contrast fix

Elementor → Site Settings → Global Colors. Replace the link green and primary amber. Nothing else in the palette moves.

# links / body accent
- #7FB432
+ #4A6B1F

# buttons
- #EB9309
+ #8A5200

# crisis strip
- #9D5BD6
+ #7C3AB7
2 · The iOS zoom bug

Safari zooms the whole page when you focus any field under 16px. Your newsletter field is a likely candidate. One rule fixes every field on the site:

input, select, textarea{
  font-size: 16px;
  min-height: 48px;
}
3 · Kill the 300ms tap delay + grey flash 
a, button{
  touch-action: manipulation;
  -webkit-tap-highlight-color: transparent;
}

Applied site-wide in Custom CSS so you don't have to touch each widget.

4 · Stop iOS inflating text in landscape 
html{
  -webkit-text-size-adjust: 100%;
  text-size-adjust: 100%;
}

Without this, Safari in landscape auto-inflates all body text and breaks every layout on this page.

5 · Home-indicator clearance

Any fixed donate button needs bottom padding or the iPhone home bar sits on top of it.

.fixed-cta{
  padding-bottom: calc(12px + env(safe-area-inset-bottom));
}
6 · Don't use 100vh on mobile 
.hero{
  height: 100vh;
  min-height: 100svh;
}

vh on mobile browsers includes the collapsing URL bar, so a full-height hero gets clipped. svh is the smallest stable viewport.

7 · Alt text on every hero and 5K image

All hero images currently ship alt="". These are the filenames on the live site, which is why they're empty:

DSC_6165-scaled-...jpg
IMG_0573-scaled-...jpg
Screenshot-2024-11-09 at 4.56.21 PM.png

Manual per image — no plugin infers these. The Instagram feed images already have captions as alt, so the site is inconsistent with itself.

8 · OG image — highest leverage, easiest win

The live page sets og:url but has no og:image. Every share on Instagram, Facebook, LinkedIn renders as a bare URL. One 1200×630 PNG fixes it.
