Wordle Daily ZIP builder

React 18 + Vite 5 · six guesses, one word a day · rewritten & repackaged

Play it now

Guess the word in six tries.

Same scoreGuess() as the project, inlined as vanilla JS.

Download the project

One click assembles a 16-file ZIP in your browser. Nothing is uploaded anywhere.

  • src/game/wordle.js — pure scoring engine, two-pass duplicate rule
  • src/game/wordle.test.js — 6 Vitest cases incl. daily-seed determinism
  • src/hooks/useWordle.js — useReducer machine, stats survive reset
  • src/components/ — Board / Row / Keyboard, staggered flip, re-keyed shake
  • server.mjs — zero-dependency static server for dist/

Then run it

cd wordle-daily
npm install
npm run dev       # http://localhost:5173
npm test          # 6 passing
npm run build     # -> dist/
npm run serve     # node server.mjs, port 4173

What changed in the rewrite

  • scoreGuess() returns { result, isWin } — the unused 3/2/1 weighting is gone
  • Flip stagger is per-cell transitionDelay, not a hardcoded constant
  • Shake re-keys off shakeToken, so a repeated bad guess replays the animation
  • Stats load once and are carried through reset instead of being re-read and clobbered
  • ALLOWED is new Set([...ANSWERS, ...EXTRA]) — it was copying the same array twice
