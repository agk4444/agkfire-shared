What changed in the rewrite

  • Scoring is a real two-pass. Greens claim the letter budget first, then yellows are handed out only from what is left. So ALLEY vs LEVEL can't produce more yellow Ls than the answer has.
  • Keyboard state never downgrades. A letter you already hit green stays green.
  • Shake on rejection re-keys the row, so the CSS animation restarts instead of silently doing nothing on a repeat mistake.
  • Answer is seeded by date (pickDaily), so every player gets the same puzzle. A "New round" button picks a random one for practice.
  • Flip animation swaps colour at the halfway point via the keyframe, with a prefers-reduced-motion fallback that just sets the colours.
  • Stats persist to localStorage: played, win rate, streak, best streak, guess distribution.
