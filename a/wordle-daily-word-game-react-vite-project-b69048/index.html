WORDLE DAILY WORD GAME

A NYT-style six-guess word puzzle as a real React 18 + Vite 5 project. Play a quick demo below, then download the full project as a ZIP.

Run it

cd wordle-react
npm install
npm run dev      # http://localhost:5173

npm run build    # -> dist/
npm run preview  # serve the production build
npm test         # vitest — the scoring rules

What's actually implemented

  • Real duplicate-letter scoring. Two passes, matching the NYT rule: greens claim their letter first, then yellows are handed out only from what's left. scoreGuess() in src/game/score.js is a pure function with unit tests for the tricky cases.
  • Flip animation. Each tile rotates on X and swaps colour at the halfway point, staggered left-to-right. Respects prefers-reduced-motion.
  • Shake on rejection. Non-word or too-short guesses bump a counter that re-keys the row, so the CSS animation restarts instead of silently doing nothing.
  • Keyboard that remembers. Marks merge with correct > present > absent priority and never downgrade a letter you've already hit.
  • Stats in localStorage — played, won, current streak, best streak, guess distribution.
  • Share copies the emoji grid, with a execCommand fallback if the clipboard API is blocked.
  • Mobile-first, dark/light toggle, server.mjs is a zero-dependency static server for dist/.
